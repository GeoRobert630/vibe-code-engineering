# Cloud & Infrastructure Security

Inspect:
- IAM
- object storage
- databases
- firewalls/security groups
- serverless functions
- containers
- Kubernetes
- Terraform/IaC
- logs
- encryption
- backups

Look for:
- wildcard permissions
- public databases
- public buckets
- exposed admin interfaces
- unnecessary network access
- production credentials in development
- privileged containers
- missing audit logs

Use least privilege and environment separation.
