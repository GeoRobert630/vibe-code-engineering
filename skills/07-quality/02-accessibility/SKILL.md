# Accessibility

Check:
- color contrast
- alt text
- semantic HTML
- keyboard navigation
- focus visibility/order
- form labels
- clear button labels
- error messages
- headings
- ARIA only when appropriate

Review both desktop and keyboard-only interaction.

Do not use color alone to communicate important state.
