# Disaster Recovery

Check:
- database backups
- storage backups/versioning where appropriate
- backup frequency
- retention
- encryption
- restore procedure
- migration recovery
- credential rotation
- incident contacts

A backup is not enough. Verify that restoration can actually work in a safe environment.

Document:
- RPO
- RTO
- restore steps
- responsibilities
- last restore test
