# Cost & Abuse Controls

Check:
- cloud budgets
- usage alerts
- API quotas
- rate limits
- AI token/request limits
- file-storage limits
- background job limits
- per-user/IP controls
- expensive-query protection

Focus especially on publicly reachable or unauthenticated expensive operations.

This is a resilience and abuse-control layer, not a replacement for IAM or authorization.
